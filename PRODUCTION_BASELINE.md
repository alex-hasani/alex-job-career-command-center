The public `v1.0` tag is an immutable, privacy-safe source snapshot created with fresh Git history. It contains fictional demonstration profile data and no private runtime state.

## Change boundary

Future work remains module- or section-scoped. Each completed change must be validated, reviewed for unrelated edits, privacy-audited, committed, pushed, and verified against the remote branch.

The public mirror must never receive private candidate data, mailbox content, application history, generated documents, databases, spreadsheets, backups, logs, credentials, or local configuration.
